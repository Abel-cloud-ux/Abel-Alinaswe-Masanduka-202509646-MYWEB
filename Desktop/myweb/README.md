# ICT251 Activity 3: Interactive Personal Website

A responsive student portfolio built with HTML5, CSS and JavaScript by Abel Alinaswe Masanduka, Mulungushi University.

**Live site:** [https://abel-alinaswe-masanduka-202509646-myweb.onrender.com]

## JavaScript features
1. **Contact form validation and preview:** rejects empty or spaces-only names and messages and invalid emails, then shows a local preview (no message is sent).
2. **Gallery viewer:** Previous and Next buttons change the photo and caption, wrapping around at the first and last photo.
3. **Theme switch:** toggles between light and dark mode.
4. **Mobile navigation:** a Menu button opens and closes the links on narrow screens.

## How to test
- **Form:** submit it empty, with spaces only, and with an invalid email (e.g. `abc`). All should be rejected. Valid input shows a preview.
- **Gallery:** click Next on the last photo and Previous on the first.
- **Theme:** click the toggle and check the text is readable in both modes.
- **Menu:** make the browser window narrower than 700px, then open and close the Menu.
