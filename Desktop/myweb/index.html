Projects and Skills

HTML5 Page Structure

I built this portfolio using semantic elements such as header, nav, main, section and footer. I also added a learning table, captioned photos, and audio and video with written summaries, so the page is clear and accessible.

Responsive CSS Design

I styled the whole site with an external stylesheet, using a consistent colour palette, the box model, and a media query so the layout works on both phones and computers.

JavaScript Interactivity

I added a validated contact form with a local preview, a photo gallery viewer, a dark and light theme switch, and a mobile menu. I learned to use functions, events and DOM updates.

Publishing with GitHub and Render

I stored my website in a GitHub repository and deployed it as a static site on Render, so it is available online through a public link.
